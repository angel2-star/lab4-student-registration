# Student Registration System

## Project Information
- **Course**: WAD621S
- **Lab**: 4 - Registration Form & Profile Cards
- **Author**: Ndina Unandapo
- **Date**: 6 September 2025

## Features
- Complete registration form with validation
- Profile card generation on submission
- Summary table that updates with each submission
- Remove functionality for both cards and table rows
- Responsive design with media queries for different screen sizes
- Print styles for better printing experience
- Custom color scheme (black, purple, red, pink)

## Files Included
- `index.html` - Main HTML structure
- `style.css` - All styling with responsive design
- `script.js` - JavaScript functionality for form validation and dynamic content

## How to Run
1. Extract all files to a folder
2. Open `index.html` in any modern web browser
3. No additional setup or server required

## Browser Compatibility
- Chrome (recommended)
- Firefox
- Safari
- Edge

## Validation Features
- Required field validation
- Email format validation
- URL validation for photo URL
- At least one interest selection required
- Year of study selection required

## Accessibility Features
- Proper labeling for all inputs
- ARIA live regions for screen reader feedback
- Keyboard navigation support
- Adequate color contrast

## Responsive Design
- Adapts to desktop, tablet, and mobile screens
- Media queries for different screen sizes
- Print-friendly styles
